# Site data schema

These files are generated by `scripts/09_build_site_data.py`, which rebuilds the directory from scratch on every run. Everything that does not depend on user input is precomputed in Python: parameter histograms and statistics, torsion profiles, the geometry of every bond, angle, torsion and improper, conformer superpositions and 2D depictions. The page only looks these up, matches queries and draws. Don't edit them by hand. All binaries are little-endian. `meta.json` lists every file with its size, gzip size and sha256.

## Indices

| Index | Meaning |
|---|---|
| `mol_idx` | Unique chemical identity (OpenFF isomeric explicit-H SMILES, RDKit backend). Used only for grouping; it never transfers atom indices. |
| `topology_idx` | One QC record: an optimization record or a TorsionDrive record. It carries its own atom order, taken from its mapped CMILES. |
| conformer | Within a topology: 1 for optimizations, one per grid point for TorsionDrives. `conf_start[t]`…`conf_start[t] + n_conf[t] - 1` are contiguous. |
| param index | Position in `params.json`. |

## JSON files (column arrays)

- **`meta.json`**: provenance (Zenodo record, QCArchive dataset, OFFXML ref and sha256, RDKit.js version and hashes), counts, QM specifications (`specs`), exclusions, validation summaries from every pipeline step, the file list and the size-gate results.
- **`params.json`**: one object per valence parameter, in handler hierarchy order.
  - Always present: `handler`, `param_id`, `hierarchy_index`, `smirks`, `tag_index` (query-atom index of tags :1..:n).
  - Bonds: `length_angstrom`, `k` (kcal/mol/Å²).
  - Angles: `angle_deg`, `k` (kcal/mol/rad²).
  - Torsions: `periodicity[]`, `phase_deg[]`, `k_raw[]` (kcal/mol), `idivf[]` (resolved; improper `auto` = 3), `k_effective[] = k_raw/idivf`.
  - Coverage: `n_molecules`, `n_topologies`, `n_assignments`, `n_obs_opt`, `n_obs_td`, `n_invalid`.
  - `opt_stats`: optimization geometries only, excluding frozen-bond rows. Linear statistics plus `mean_minus_centre` for bonds and angles; circular statistics for torsions.
  - `detail`: path of the parameter's detail file (`param/<param_id>.json`).
- **`molecules.json`**: `display_smiles` (RDKit, no H), `charge`, and `topologies[]` for each `mol_idx`.
- **`topologies.json`**: per `topology_idx`:
  - `source` (`opt` or `td`), `entry_name`, `record_id`, `mol_idx`, `n_atoms`;
  - `mdl_smiles`: OpenFF's MDL-aromatic, explicit-H SMILES. Load it in RDKit.js with `{setAromaticity:false, kekulize:false, removeHs:false}`.
  - `mdl_order`: `mdl_smiles` atom *n* corresponds to topology atom `mdl_order[n]`;
  - `conf_start`, `n_conf`;
  - `coord_offset`: in atoms, into `coords_<source>.bin`;
  - `driven`: TorsionDrive dihedral (0-based), or `null`;
  - `frozen`: frozen dihedrals of constrained optimizations;
  - `unassigned_propers`: proper torsions that no Sage parameter matches;
  - `frame_order`: TorsionDrive records only (else `null`): conformer offsets (0 … `n_conf` − 1) in ascending grid angle, the frame order of the 3D scan animation.
- **`conformers.json`**: per conformer (global index = `conf_start + j`): `record_id` (the optimization record), `grid_deg`, `rel_energy_kcal` (relative to the drive minimum), `energy_hartree` (final QM energy), `opt_group_rel_kcal` and `opt_group_same_level` (optimization records of a molecule with more than one record: energy relative to the lowest, given only when all are at the same QC level; else `null`), `spec` (index into `meta.specs`), `connectivity_changed` (diagnostic only).
- **`param/<param_id>.json`**: everything a parameter page shows, one file per covered parameter (lazy).
  - `weightings.instances` and `weightings.molecule`: the distribution over optimization records (frozen-bond rows and undefined dihedrals excluded). Each observation has weight 1 (impropers: 1/3 per trefoil term); with `molecule` weighting the weights of each molecule are rescaled to sum to 1. Each has `n_obs`, `n_mol`, histogram range and bin count `lo`, `hi`, `nb`, weighted `counts`, and `stats` (linear, or circular for torsions). `{"n_obs": 0}` when nothing is observed.
  - `profile` (torsions): Σ k_eff (1 + cos(nφ − phase)) at 1° steps (`x0` = −180, `step`, `y`, kcal/mol) and its local `minima` (`phi`, `energy`).
  - `examples`: `[topology_idx, atoms, source]`, the first assignment in each topology.
  - `scans` (torsions): TorsionDrives whose driven dihedral this parameter covers: `t`, `atoms`, and `frames` = `[grid_deg, rel_energy_kcal, conformer]` sorted by grid angle.
- **`conformer_groups.json`**: superposed optimization conformers, for molecules with more than one optimization record. Keyed by reference `topology_idx`; each entry lists every other record `t` of the molecule with `coords` (flat xyz, Å, in `t`'s atom order, rigidly superposed onto the reference by heavy-atom Kabsch without reflection) and the `rmsd` of exactly those coordinates. Computed by `scripts/08d_align_conformers.py`.
- **`canonical_smiles.json`**: per `mol_idx`, the canonical SMILES that the vendored RDKit.js writes for `display_smiles`. An exact-match query is a string comparison against this list.
- **`depictions/<k>.json`**: 2D depictions of topologies `first` … `first + 499` (`k = first / 500`), from `scripts/08e_depictions.py`. Per topology: `molblock_h` (explicit-H, RDKit native 2D coordinates, kekulized, wedged, atom order = topology order; the 3D viewer replaces only its coordinates with QM coordinates), `molblock_heavy` (same drawing after RDKit `RemoveHs`, which keeps some hydrogens, e.g. those needed to define stereochemistry), `heavy_index` (topology atom → atom in `molblock_heavy`, −1 if removed), and `bonds_h`, `bonds_heavy` (the `[a, b]` atom pairs of each molblock's bonds, in bond order).
- **`molecule_svgs/<k>.json`**: pre-rendered unhighlighted SVGs (260 × 190) of molecules `first` … `first + 499`, for the similarity and substructure result cards.

## Binary files

**`coords_opt.bin` / `coords_td.bin`**: Float32 xyz in Å. Conformer *j* of topology *t* starts at float index `3 * (coord_offset[t] + j * n_atoms[t])`.

**`fp_morgan.bin`**: Uint8 array of shape `[n_molecules, 256]`. Morgan fingerprint, radius 2, 2048 bits, computed by the vendored RDKit.js from `display_smiles`. Bit *i* is in byte *i*/8, least-significant bit first, exactly as `get_morgan_fp_as_uint8array` returns it.

**`fp_popcount.bin`**: Uint16 per molecule, the number of set bits in its `fp_morgan.bin` row (the Tanimoto denominator).

**`geom_opt.bin`** (schema 2): every bond, angle, proper torsion and improper "star" (a central atom with at least three neighbours and each 3-subset of them) of every optimization record, measured with RDKit on the Float32 coordinates in `coords_opt.bin`, whether or not a Sage parameter covers it. A SMARTS geometry query reads its values here. Written by `scripts/05b_geometry_universe.py` and packed by `09`.

| Offset | Type | Content |
|---|---|---|
| 0 | Uint32 ×6 | schema (2), `nTop`, `n_bond`, `n_angle`, `n_proper`, `n_improper` |
| | | then, for each kind in the order bond, angle, proper, improper: |
| | Int32 ×(nTop+1) | row start of each topology (TorsionDrive topologies have no rows) |
| | Int16 ×k·n | atoms; k = 2, 3, 4, 4. Impropers: central atom first, then the outer atoms sorted |
| | Int16 ×n | param index in `params.json`, −1 = no Sage parameter |
| | Uint8 ×n | flags: bit 0 = valid dihedral (not near-linear), bit 1 = proper torsion about a frozen bond |
| (pad to 4) | Float32 ×w·n | values; w = 1, 1, 1, 3. Improper: the terms (c,a,b,d), (c,b,d,a), (c,d,a,b) for central c |

Units and sign conventions are the same as for the values in `data/processed/shards/` below.

**Per-parameter shards (not served)**: `data/processed/shards/<param_id>.bin` holds the observations of one parameter. `09` computes `param/<param_id>.json` from them and the tests use them; the site does not load them.

| Offset | Type | Content |
|---|---|---|
| 0 | Uint32 ×4 | schema (1), `nAsg`, `nRows`, `width` (1; impropers 3) |
| 16 | Int32 ×nAsg | topology of each assignment (assignments in `label_molecules` order) |
| | Int16 ×4·nAsg | atoms as returned by `label_molecules`, −1 padded. Impropers: atom 2 is central. |
| | Uint8 ×nAsg | flags: 1 = torsion about a TorsionDrive-driven bond, 2 = about a frozen bond, 4 = the driven dihedral itself |
| (pad to 4) | Float32 ×nRows·width | values: rows = each assignment × its topology's conformers, in order |
| | Uint8 ×nRows | torsions only: 1 = valid, 0 = undefined (near-linear, min sin θ < 0.02) |

The values are bond length (Å), angle (°), or signed dihedral (°, IUPAC/OpenMM) in the `label_molecules` atom order. For impropers they are the three trefoil dihedrals in the (central, a, b, c) order Interchange passes to OpenMM.

**`assignments.bin`**: per-topology parameter assignments.

| Offset | Type | Content |
|---|---|---|
| 0 | Uint32 ×3 | schema (1), `nTop`, `nRows` |
| 12 | Int32 ×(nTop+1) | row start of each topology |
| | Uint16 ×nRows | param index |
| (pad to 4) | Int16 ×4·nRows | atoms, −1 padded |
